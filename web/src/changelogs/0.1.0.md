I've decided to reset the version from v2.2.0 back to v0.1.0. The API structure is still a bit unstable, and there are many edge cases I haven't fully tested yet. Plus, not every link supported by yt-dlp might work perfectly here right now. Because of this, a version reset makes sense to reflect that the project is still in its early stages. However, all the core features are fully functional and ready to use!

Grips also got a major rebranding and UI overhaul. As you can see, the new design is much cleaner and easier on the eyes. Most importantly, it finally has its own identity and no longer heavily borrows from the cobalt.tools design! :3

### UI Improvements

- Added a new landing page for Grips, completely redesigned the UI/UX, and polished the overall look.
- Fixed a bug where the loading state (after pressing the 'Add Queue' button) would disappear if you navigated to another page before it finished.

### Download Improvements

- Fixed an issue causing inconsistent audio quality in downloads.
