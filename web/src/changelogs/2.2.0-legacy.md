> This is the legacy version of Grips before the versioning was reset to v0. The core functionality remains mostly the same and works perfectly fine. However, the UI is outdated, so we highly recommend trying out the newer, fresher version.

The download flow has been completely overhauled in this update. Instead of just returning a direct media link from the provider, the server now downloads the video to its own storage first, and then provides a direct download link straight from the server.

The old method relied on the provider's direct URL staying active and consistently serving the file. This caused issues because links generated by media providers (like YouTube) often throttle speeds or block access entirely.

### Download Improvements

- Completely revamped the download flow.
- Fixed YouTube download errors caused by the `tv_downgraded` API changes ([source](https://github.com/yt-dlp/yt-dlp/issues/17389)).
- Added server-side h264 video recoding. This is especially useful for video editors and can be enabled in the settings.
